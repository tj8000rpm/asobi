# ちいさな くうこう

羽田をモチーフにした、幼児向けの空港あそび。海沿いの空港を上から見ながら、航路を飛ぶ飛行機を案内します。スマホ縦画面向け、静的HTML・CSS・JavaScriptとlocalStorageだけで動きます。

## 起動

```sh
python3 scripts/build.py
python3 -m http.server 8000 --directory dist
```

http://localhost:8000/airport/index.html を開きます。スマホでは同じWi-Fiに接続し、`http://PCのLANアドレス:8000/airport/index.html` を開いてください。リポジトリルートで実行してください。変更後は再度 `python3 scripts/build.py` を実行してページを再読み込みします。

## 自動運航

A・C滑走路は北から南への着陸（A：16R、C：16L）にしています。到着航路と待機ルートを画面上側へ配置しています。

飛行機は画面外から点線の航路へ入り、旋回して滑走路の延長線に合流し、機首を合わせて直線進入・着陸します。接地後は滑走して誘導路を通り、ターミナルへ向かいます。操作しなくてもこの流れが続きます。

予定の滑走路が使用中なら、海上の待機ルートを周回します。自動運航では周回の合流点まで戻ってから、空いた滑走路へ進入します。

滑走路は進入開始から接地後の滑走完了まで予約され、二重には割り当てません。到着は6秒間隔、画面内は地上の機体を含め最大12機。満員時は新たな到着を保留します。ブラウザが非表示の間と「おやすみ」中は進行を停止し、復帰時の早送りはしません。

## 操作とスコア

空港マップは画面の高さに合わせて広がります。上部は小さなタイトルとスコア・着陸数・待機数、音・一時停止をまとめたバー、下部は滑走路ボタンです。遊び方は右上の「?」で開けます。機体ラベルは選択中または待機中のものに絞っています。

飛行中・待機中の機体をタップすると、その機体と予定航路が強調されます。地図の滑走路か、下のA・B・C・Dボタンをタップすると案内先を変更できます。

飛行中の変更は航路の先の進入先へ反映されます。待機中の変更は現在位置から旋回して新しい進入ルートへ接続します。

- 手動で空いている滑走路へ案内：着陸時に10点
- 機体のおすすめ滑走路への手動案内：着陸時に20点
- 上空待機している機体への手動案内：さらに5点
- 自動着陸：着陸回数が増加、加点なし

使用中の滑走路をタップしても、案内先は変更されず、衝突や減点はありません。音は初期状態でオフです。

## モチーフ

A・Cの平行滑走路、斜めのB・D、沖合のDと連絡路、ターミナルと東京湾を簡略化した地図です。実在の運用や進入方式の厳密な再現ではなく、4本への着陸を楽しむゲーム用の航路・時間・位置関係です。

参考：[国土交通省・羽田空港の飛行経路](https://www.mlit.go.jp/koku/haneda/action/)、[東京国際空港の概要](https://www.ktr.mlit.go.jp/ktr_content/content/000933025.pdf)。

## 構成・保存

公開ファイルは `public/`、このゲームのテストは `tests/` に置きます。以下のファイル名は `public/` 内のものです。

- `index.html`: SVGの空港地図、飛行機、操作パネル
- `style.css`: スマホ向け画面
- `simulation.js`: 共通座標、航路、機首方向、待機・進入・滑走・地上移動、予約と加点
- `game.js`: 地図への描画、操作、効果音、保存

外部ライブラリ・外部通信・サーバー処理は不要。そのまま静的ホスティングできます。

`little-airport-v1` に累計着陸回数・スコア・音設定を保存します。前版の保存も引き継ぎます。保存拒否・不正データがあっても遊べます。機体の運航状況はページを開くたびに初期化されます。

## テスト

```sh
python3 -m http.server 8001
```

リポジトリルートで上記を実行し、http://localhost:8001/games/airport/tests/index.html を開きます。Chromiumがあれば `python3 scripts/test_browser.py` でも実行できます。

航路上の移動、機首の正対、案内変更時の位置連続性、自動着陸、周回待機、滑走路の予約・解放、15分間の自動運航、加点を確認します。保存・一時停止と実機での操作はゲーム画面で確認してください。実機での描画と音は別途確認してください。
